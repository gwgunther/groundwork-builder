Novel components (4)
Centered Text + Scattered Photo Collage
Patient portraits float at absolute positions around a centered headline/CTA block. Not a filmstrip — requires independent absolute placement or named grid areas. Teal smiley doodle as a floating SVG element.
Scale-Inversion Heading + SVG Underline
Small centered text block above an oversized black-weight headline below — reversed convention. Key phrase receives a teal SVG curved underline (not CSS text-decoration). Recurring signature across hero, about, and case-studies.
Three-Zone Hamburger Nav
Logo left · MENU trigger center · phone number right. No inline nav links in default state. Trades navigability for visual cleanliness and permanent phone number prominence.
Inverted Purple Featured Treatments Block
Full-width deep purple (#5B2D8E) section — the only dark/inverted surface in the template. Teal eyebrow label on purple, white headline, light-purple body text. Functions as a visual climax on service detail pages.
Fidelity checks (12)
Hero headline must be black-weight grotesque sans (800+) at 80px+ — no serif, no editorial scale.
Teal (#5ECFB1) appears only as SVG doodle/stroke graphic. Never as button fill, background, or text color in default sections.
CTA buttons use outline treatment only — transparent fill, black border, black text, pill radius. No filled primary button.
Nav must be the three-zone hamburger pattern: logo / MENU center / phone right. No inline nav links visible in default state.
Scale-inversion pattern: small centered text block above, oversized headline below. Do not place large headline first.
Hand-drawn SVG curved underline beneath key headline phrase — not CSS text-decoration:underline.
The featured-treatments/inverted section must use deep purple (#5B2D8E) — this is the only dark/inverted surface in the template.
Team portraits must use a cool neutral background (not warm/tinted) with consistent square or near-square crops.
Patient photos may be vivid and slightly saturated — no warm ivory grading required. Teal-blue background on patient close-ups is consistent with source.
Smiley face and lasso/oval doodle motifs must be SVG line-art in teal, not emoji or raster images.
All heading text in sentence case. Eyebrow labels in all-caps with wide letter-spacing. No title case or mixed-case headlines.
Two primary surfaces only (canvas #F5F0E8 + white #FFFFFF) plus one inverted purple. No warm tinted intermediate surface.
