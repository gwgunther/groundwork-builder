Novel components (4)
Social Proof Avatar Strip
Overlapping circular avatar thumbnails with headcount label ("+300 Happy Patients") in the hero section below the main image. Micro-social-proof element, not a full testimonial block.
Tabbed Package Selector Panel
Pill-tab nav (2–4 care tiers) drives a two-column content panel: contextual photograph left, tier name + checklist + CTA right. Tab-switching updates panel content inline without page navigation.
Intent-Segmented Contact Cards
Three stacked cards replacing a contact form. Each card addresses a distinct patient intent (schedule, call, find us) with a distinct icon, short description, and a labeled CTA. Sits in right column of a split with a map in the left column.
Split Image-Accordion FAQ
FAQ section uses a two-column split: large rounded lifestyle image in left column (~45% width), FAQ accordion in right column. Image is sticky, providing grounding context as the user expands questions.
Fidelity checks (12)
Hero must be a left-right split (large headline + CTA left, single image card right). Do not center the hero headline.
Headline emphasis: key phrase uses forest-green (#3A5244), setup words use dark charcoal (#1A1F1A). Same sans family, similar weight. No italic or uppercase.
Buttons are rounded-rectangle (lg ~10px radius), NOT full pill/capsule. Key distinction from pill-button systems.
Outer canvas is sage-green (#4A5C4E) — must appear as the page frame cards float against. Not white.
Service packages use horizontal pill-tabs (not vertical list or carousel) to switch between care tiers.
FAQ uses the split layout: image left (~45%), accordion right (~55%). Not a full-width accordion stack.
Contact section must use intent-segmented action cards (3 cards: schedule, call, find us) alongside a map — no contact form.
Photography grading is clean neutral (bright studio), NOT warm/ivory. Neutral gray or white backgrounds on subject images.
Social-proof strip in hero: overlapping circular avatar thumbnails in a row with a patient headcount label.
Testimonials appear in two modes: 3-column card grid AND a separate featured full-width split (image left, pull-quote right).
Eyebrow chips include a small icon prefix alongside the label text — not plain text-only chips.
Button CTAs use an arrow icon prefix (→ or SVG arrow) as a design signature of this template.
