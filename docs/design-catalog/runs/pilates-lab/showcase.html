Novel Components (3)
Sage Canvas Page Frame
html/body background is sage green (#D9DFD3). The entire site content lives in a warm cream (#F7F5F0) rounded container card (radius ~22px) — creating a visible colored border around the whole page. No section inside the container repeats the sage color.
Asymmetric Overline + Giant Serif H1 + Icon Card Grid
Overline is right-anchored; large italic serif H1 spans full width below it. Four icon-card cells in 2-column grid — each with a pale sage icon container (not accent-colored), bold sans label, 2-line description. White cards, flat, no borders.
Founder Split with Giant Pull-Quote
Two-column layout: portrait photo left, right column starts with uppercase overline, then a very large italic serif pull-quote (doctor's philosophy as headline), then 3 short bio paragraphs, then name+role. No CTA button. No cursive signature. The pull-quote is the hero of the right column.
Fidelity Checks (12)
html/body background must be sage green (#D9DFD3). Never white or off-white as the outermost background.
Content container must have large corner radius (~22px) visible against the sage canvas — this is the template's defining signature.
Section labels are plain uppercase tracked sans-serif overlines — no pill badge, no border, no background container.
Primary CTA button uses near-black fill (#1C1C1A) with large (not pill) radius (~10px). Do not use the pill radius system.
Nav uses an outline/ghost button for the CTA — not a filled primary button. Always opaque cream background at all scroll positions.
Typography emphasis is scale only — large italic serif H1 vs small compact sans body. No color-shift hover states.
All image containers and cards use large corner radius (~16–20px) consistently throughout.
Depth achieved through three-tier surface system (sage → cream → white). Zero box-shadows or drop-shadows anywhere in the design.
Icon cells in the why-us section use pale sage (#EEF0EB) rounded-square containers — not circles, not accent-colored.
Doctor/founder quote section: pull-quote as large italic serif headline, followed by bio paragraphs and name/role. No cursive signature, no pill CTA in this block.
Photography grading is cool-neutral to warm-neutral — not warm ivory/linen. Clean, natural-light wellness photography.
Body copy paragraphs are 2–4 sentences with generous line-height. Never dense continuous prose.
