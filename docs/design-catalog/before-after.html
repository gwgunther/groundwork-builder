01 — The creative engine

Where designs come from

Before

Constraint-based variation

  • 8 synthetic archetypes — one pick locks all 9 section variants via a fixed table
  • ~30 components, closed set — two sites sharing an archetype are structurally identical
  • Inspo library is decorative — references reduced to adjectives & trait strings; the director never sees the design
  • Fonts hash-seeded from 20 pairings; creativity = combinatorics
  • Groomify-style layouts not expressible
After

Curated reference catalog

  • Each reference is its own archetype — explicit variant map, freed from the 8-row table
  • Full design system per entry — token strategy, type anatomy, atoms, layout grammar, imagery recipe, voice
  • De-branded, two axes — brand identity stripped to reference fields; industry translated to dental
  • Honest gaps — what the renderer can't do yet is named work (novel[], fidelity.gaps), never silently flattened
  • Taste decided at curation, not re-litigated per build
02 — The auditors

From taste police to fidelity QA

The 13 hard penalties split: 3 are correctness (never suppressible), 10 are taste — suppressible per-build when a curated reference legitimately uses the pattern. The critique gate becomes “technically sound and faithful to the reference.”

  • Fixer skills receive directives: improve execution of deliberate choices, never remove them
