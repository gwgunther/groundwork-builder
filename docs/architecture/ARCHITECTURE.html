Deterministic vs Agentic — what each phase actually does

Phase Deterministic (code) Agentic (Claude) What constrains the agent
1. Scrape Playwright crawl, asset extraction, color sampling. — n/a
2. Audit PageSpeed API, GBP Places API, HTML scanners (tech / trust / hosting / conversion), HTML report render. AI Site Audit — qualitative findings ("the tone reads transactional," "missing trust signals"). skills/audit/site-audit.md + raw findings as input.
3. Design Reads scraped colors + fonts; loads past builds from _memory/library/. Silver extraction (structured data), Creative Director (variant + color choices), brand-direction. scripts/pipeline/skills/design.md + taste-frontend.md, docs/design/DESIGN_RULES.md, design-dna.ts schema, past-builds for divergence.
4. Content Page inventory, URL mapping, redirect rules. Content map (keep/optimize/create per page), section briefs, hero/service/faq/cta content, blog rewrites. skills/content/*.md, skills/copywriting.md, positioning.md, vertical preset.
5. Inject + Build Clone template, find-and-replace placeholders, run astro build, validate output. — The design-dna.ts from phase 3 picks which variants get injected.
6. Publish Cloudflare API (project create, custom domain, DNS CNAME), git push, deploy poll, PageSpeed re-run, rescan diff. — n/a
7. Pitch Render pitch.html with measured before/after data. Git push to dental repo. Airtable Build row write. Pitch copy generation — headline, value props, call-to-action wording. skills/content/cta.md + before/after numerical facts.
Mental model: the pipeline is a deterministic conductor calling agentic specialists. The conductor decides phase order, retries, where files land, when to deploy. The specialists decide what the site looks like and what it says. The reference files (skills, prompts, design rules) are how you tell the specialists what "good" looks like — change them, the next run inherits the new standard automatically.

How to extend the pipeline

Add a new design variant (e.g. radius: 'very-round')

  1. Add the option to the union in src/config/design-dna.ts.
  2. Implement the matching variant file in src/components/variants/<section>/.
  3. Update skills/design/derive-design-tokens.md (or the Creative Director prompt) so the agent knows the new option exists.
  4. Optionally bias selection by adding "use X when Y" rules to docs/design/DESIGN_RULES.md or scripts/pipeline/skills/taste-frontend.md.

Add a new principle for AI-generated copy

Edit skills/copywriting.md (or the specific section skill like skills/content/hero.md). The next run reads the change automatically — no code change needed.

Add a new pipeline phase

Three things to wire up: (a) the deterministic orchestrator step in build-site.js or audit-site.js, (b) a new skill file at skills/<category>/<skill>.md, (c) a new ai-<phase>.js in scripts/pipeline/lib/ that loads the skill and makes the Claude call.
